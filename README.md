# 🐾 SIGAS — Sistema Integrado de Gerenciamento de Animais Silvestres

> **Projeto Integrador — Universidade Virtual do Estado de São Paulo (UNIVESP)**

O **SIGAS** é um sistema web desenvolvido para otimizar o controle de entrada, triagem, acompanhamento clínico e destinação de animais silvestres resgatados por órgãos ambientais, ONGs e centros de triagem (CETAS/CRAS).

---

## 🎯 Objetivo do Projeto

Oferecer uma solução digital centralizada para substituir fichas físicas e planilhas manuais, garantindo maior rapidez no atendimento veterinário, rastreabilidade dos animais resgatados e geração de relatórios estatísticos para suporte à gestão ambiental.

---

## 🚀 Funcionalidades Principais

- **Cadastro de Resgates:** Registro detalhado da ocorrência, local de resgate, espécie e condição inicial do animal.
- **Prontuário e Acompanhamento:** Histórico médico, registro de medicação e evolução do quadro clínico.
- **Controle de Recintos:** Gestão da ocupação de quarentenas, gaiolas e viveiros.
- **Registros de Destinação:** Controle de solturas, transferências para outras instituições ou óbitos.
- **Relatórios Gerenciais:** Consultas e indicadores de espécies atendidas e taxas de reabilitação.

---

## 🛠️ Tecnologias Utilizadas

- **Front-end:** HTML5, CSS3, JavaScript
- **Back-end:** PHP
- **Banco de Dados:** MySQL
